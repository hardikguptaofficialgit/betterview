## Detailed Description

BetterView AI elevates your AI conversations on Google Gemini and Grok by rendering structured answers as rich, interactive visual components directly in the chat stream.

Instead of plain markdown walls of text, get clean visual diagrams, responsive tables with numeric formatting, step-by-step guides, interactive comparisons, charts, quizzes, and timelines designed to clarify complex information instantly.

### Key Features

- **12 Interactive Visual Components**:
  - **Flow Diagrams**: Architecture diagrams and process maps with orthogonal edge routing.
  - **Step-by-Step Guides**: Linear sequential instructions with collapsible details.
  - **Tables**: Formatted tabular views with auto-detected numeric alignment and currencies.
  - **Comparisons**: Side-by-side pros vs cons, trade-off analysis, and option matrices.
  - **Charts**: Bar, line, radar, pie, and doughnut charts powered by Chart.js.
  - **Mermaid Diagrams**: Sequence diagrams, class diagrams, state machines, and ER diagrams.
  - **Interactive Quizzes**: Multiple-choice knowledge checks with instant explanations.
  - **Callout Banners**: Distinct notice cards for warnings, tips, success announcements, and info.
  - **Stats & Metrics**: Headline KPI cards with change deltas and trend hints.
  - **Tabbed Views**: Clean categorized text and lists in organized panels.
  - **Timelines**: Chronological milestones, roadmaps, and event trackers.
  - **Follow-up Chips**: One-click suggestion prompts to keep the conversation flowing.

- **Native Chat Integration**:
  - Components render inline inside Gemini (gemini.google.com) and Grok (grok.com) chat windows.
  - Smooth streaming experience: raw code block JSON is concealed seamlessly while the visual skeleton mounts.
  - Expand view: zoom any component into a centered modal view.
  - Data copy & source: inspect the raw spec or copy data with a single click.

- **Tailored Design System**:
  - Clean pastel palette with automated light and dark mode synchronization.
  - Crisp Phosphor icon set with duotone headers and regular chrome icons.
  - Built with pure TypeScript and zero remote dependencies.

- **100% Private & Offline**:
  - No data is ever transmitted to any external server.
  - All parsing and rendering happens locally on your device.
  - Free and open-source.

### Getting Started

1. Install BetterView AI.
2. Click the extension icon and select "Set up" for Gemini or Grok.
3. Chat as usual! Gemini and Grok will automatically format suitable answers into visual cards.
